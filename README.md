# File Backup

Aplicação Console desenvolvida em C#/.NET para realizar backups de diretórios de forma automatizada.

O projeto tem como objetivo praticar e consolidar conceitos de desenvolvimento backend com .NET, trabalhando principalmente com manipulação de arquivos e diretórios, configuração externa e organização de código.

## Objetivo

A aplicação recebe as configurações de diretório de origem e destino através de um arquivo `appsettings.json` e realiza uma cópia completa do diretório configurado.

Cada backup é criado utilizando o nome do diretório original juntamente com a data da execução.
